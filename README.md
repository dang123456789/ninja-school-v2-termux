# Ninja-Termux

## Cài đặt nhanh

Mở Termux và chạy:

pkg update -y && pkg install -y git && git clone https://github.com/dang123456789/Ninja-Termux.git && cd Ninja-Termux && bash install.sh

## Chạy Ninja

bash start.sh

## Chạy Web

bash start-web.sh

Sau đó mở trình duyệt:

http://127.0.0.1:8080
